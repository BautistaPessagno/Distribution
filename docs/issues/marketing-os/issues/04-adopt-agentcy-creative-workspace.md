# Adopt The Agentcy creative-workspace patterns

Type: research
Status: resolved

## Question

Which The Agentcy features fit the AI-account-only MVP, and what should MarketingOS defer?

## Answer

MarketingOS should adopt the AI-Host plus deterministic-workspace split, structured Creative Pieces, tokenized Brand Kits, atomic versioned edits, validation, preview, templates, backlog, and planned dates. It should prepare grounded image prompts and import AI-Host results while deferring model APIs, video, direct publishing, platform analytics, stock services, and automated reach behavior.
