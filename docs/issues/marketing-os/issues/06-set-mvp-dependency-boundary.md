# Set the MVP dependency boundary

Type: grilling
Status: resolved

## Question

Which accounts and external services may the core MVP require?

## Answer

The core requires one MarketingOS MCP gateway, an existing AI Host, and a project-domain implementation for each Connected Project. Ordinary social or advertising accounts may be optional manual destinations. No additional creative vendor, model API, model subscription, stock service, video service, or automation platform may be required. The reference products are inspirations, not integrations.
