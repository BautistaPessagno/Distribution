# Adopt Marketing AGI as the reasoning grammar

Type: research
Status: resolved

## Question

Which Marketing AGI mechanisms should become native MarketingOS behavior, and which parts must remain reference material?

## Answer

MarketingOS should adopt progressive routing, sourced Project Context, visible unknowns, artifact-first outputs, typed handoffs, versioned rubrics, and predeclared experiments. It must add persistence, approvals, jobs, scheduling, measurement ingestion, and native SEO while avoiding a runtime dependency or a single giant prompt. See [the Marketing AGI source review](../research/marketing-agi-deep-dive.md).
