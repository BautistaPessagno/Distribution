# Choose the dashboard's first-use loop

Type: grilling
Status: resolved

## Question

What should the Operator see and do first after opening MarketingOS for a Connected Project?

## Answer

The home screen is a project-aware Today view. It shows the recommended or due work, upcoming Creative Pieces, an undated Content Backlog, a calendar, and visible lifecycle states, with a prominent action to create a new Creative Piece. The calendar expresses the plan; it does not imply automatic publishing. The Agentcy dashboard screenshot supplied by the user is the visual and interaction reference.
