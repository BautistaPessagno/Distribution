Creative Piece workflow — logic prototype

The question this demo answers: does the chosen Creative Piece workflow feel right once you push it through real cases? The model under test: lifecycle backlog → drafting → review → approved → planned → exported → measured (with changes-requested back to drafting), atomic edit batches with optimistic concurrency (stale base version rejected), Brand Kit tokens that repaint drafts live but flag approved work as brand-outdated until re-approval, brand-check errors blocking approval while quality findings only advise, strip-and-save templates, and PNG-bundle export. Poke at it freely or run the guided walkthroughs.
